# Servicio de inventario

Endpoint PHP para consultar existencias y alertas, registrar entradas y salidas y mostrar el historial. Los movimientos usan transacciones para mantener la consistencia del stock.

Endpoint desarrollado en PHP que permite gestionar el control de existencias, consultar productos, visualizar alertas de stock, registrar entradas y salidas de inventario, así como consultar el historial de movimientos. Implementa transacciones para garantizar la integridad y consistencia de las existencias durante cada operación.
