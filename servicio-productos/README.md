code# Servicio de productos

Endpoint PHP para consultar, buscar, registrar, actualizar y desactivar productos. Las operaciones de escritura requieren rol Administrador.



Actualización de productos

El servicio de productos permite consultar y administrar la información
de los productos registrados en el sistema.

 Funcionalidades

- Consultar productos.
- Buscar productos.
- Registrar productos.
- Actualizar información de productos.
- Desactivar productos.

 Objetivo

Facilitar la gestión de la información de los productos y mantener
organizados sus datos dentro del sistemas
